Research

Zero-infrastructure retrieval for LLM agent tool discovery.

OKTS: Open Knowledge Tool Search
(Progressive Tool Disclosure with Portable Descriptors)

Preprint, 2026 · submission to arXiv cs.IR in preparation

LLM agents are increasingly wired to hundreds of tools, and loading every tool's JSON schema up front costs tokens in proportion to the catalogue rather than the task — re-paid on every turn. The usual fix, RAG over tool embeddings, trades that for standing infrastructure: a model to host or an API to call, a vector store to maintain, and a re-embedding pass on every catalogue change. OKTS describes each tool as a portable, git-versioned Markdown descriptor and serves any catalogue behind a fixed three-tool interface (search_tools, load_tool, call_tool) via progressive disclosure. Ranking uses a fully offline hybrid of BM25 and a deterministic feature-hashing embedding — no model, no API, no vector store, nothing to re-embed.

94.1%fewer schema tokens
92.7 → 97.6%top-1 selection accuracy
100%collision avoidance

Measured over 148 tools adapted from 20 widely used MCP servers. The ablation is reported as measured, including where it is null: the gain comes from fusing the two lexical signals — neither reaches it alone — and not from the category hierarchy or graph expansion, which are accuracy-neutral on this corpus. Every number in the paper is emitted as a LaTeX macro by the evaluation harness, so no figure is typed by hand.

Open Source

One line of work, three runtimes — each attacking tool/knowledge discovery without a vector database.

OKTS

Source-agnostic runtime that ingests tools from MCP servers, functions, HTTP/OpenAPI endpoints and sub-agents, describes each as a portable OKT markdown file, and exposes exactly three meta-tools to any agent. Graph- and hierarchy-aware retrieval over the descriptor bundle.

mcpokfretrievalpythonapache-2.0

concept-router

A zero-infra MCP server that turns an Open Knowledge Format (OKF) bundle — a directory of markdown concept files with YAML frontmatter — into fast, lexical-first knowledge discovery for LLM agents. No vector DB, no embeddings by default.

mcp-serverokfbm25rrf

SpecRouterMCP

High-performance MCP server that dynamically converts massive OpenAPI/Swagger specifications into executable LLM tools on the fly — so an agent can address an API surface far larger than its context window.

openapibm25fcontext-engineeringscalable-mcp

AgentShield

Framework-agnostic security middleware that wraps any agent runtime — Claude, Copilot, LangGraph, AutoGen, CrewAI — and enforces defences against the OWASP ASI threat classes without rewriting the agents.

agent-securityowasp-asimiddleware
